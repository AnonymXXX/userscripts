# 三角洲行动地图助手

用于收纳三角洲行动官方地图的 Tampermonkey 辅助脚本。每张地图使用独立的 `.user.js` 文件，便于单独安装和更新。

## 当前脚本

| 地图 | 脚本 | 功能 |
| --- | --- | --- |
| AZ3 | [`scripts/az3-helper.user.js`](scripts/az3-helper.user.js) | 修复出生点筛选与按钮遮挡，标注出生点及其刷新关系；补充大保险箱点位及开启状态对比图 |

### AZ3 大保险箱

- 在“密钥刷新点”后提供同级的“大保险箱点位”独立栏目。
- 当前收录 5 个点位，分别与“燃料储罐”“托卡马克面板”“乏燃料堆体”“污水净化器”和“仿星控制柱”使用相同地图坐标。
- 点击不同点位的橙色图标可查看对应的“未开启 / 已开启”实景对比图。

## 安装

1. 安装 Tampermonkey 浏览器扩展。
2. 打开对应的 `.user.js` 文件并查看 Raw 内容。
3. 在 Tampermonkey 中确认安装或更新。

脚本作用于三角洲行动官方地图页面：

`https://df.qq.com/cp/a20240729directory/*`

## 新增地图脚本

将新脚本放入 `scripts/`，文件名使用 `<地图名>-helper.user.js` 格式，并在“当前脚本”表格中补充说明。
